# Business Metrics Analyzer 

Учебный проект по дисциплине «Проектирование и разработка бизнес-ориентированного программного обеспечения». 

## Бизнес-задача 

Расчёт и визуализация ключевых показателей эффективности (KPI) предприятия. 

## Стек 

- Python 3.10+ 
- pandas 
- matplotlib 

## Запуск 

python -m venv .venv
source .venv/bin/activate # или .venv\Scripts\activate для Windows 
pip install -r requirements.txt 
python main.py

## Пример бизнес-задачи

Руководителю предприятия необходимо ежемесячно отслеживать выручку и затраты, чтобы оценивать эффективность работы компании и вовремя находить направления с низкой прибылью.

Приложение Business Metrics Analyzer помогает рассчитать среднюю выручку, прибыль и рентабельность, а также сравнить показатели за разные месяцы. Это сокращает время ручных расчётов и помогает принимать обоснованные управленческие решения.
