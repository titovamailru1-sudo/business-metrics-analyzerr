# Бизнес-требования к приложению Business Metrics Analyzer

## 1. Цель
Автоматизировать расчёт и визуализацию ключевых показателей эффективности (KPI) предприятия, чтобы руководитель мог оперативно оценивать финансовое состояние бизнеса без ручных расчётов в Excel.

## 2. Заинтересованные стороны
- Руководитель предприятия — получает сводные показатели для принятия решений
- Бизнес-аналитик — использует приложение для регулярной отчётности

## 3. Функциональные требования
- Загрузка данных о выручке и затратах по месяцам
- Расчёт средней выручки за период
- Расчёт рентабельности в процентах
- Вывод результатов в консоль
- Построение графиков динамики показателей (matplotlib)

## 4. Нефункциональные требования
- Язык разработки: Python 3.10+
- Запуск на Windows, macOS и Linux
- Расчёт на небольших наборах данных занимает не более нескольких секунд
- Код хранится в Git-репозитории, изменения вносятся через Pull Request

## 5. Ограничения
- Учебный проект: используются тестовые данные, а не данные реального предприятия
- Интерфейс консольный, графического интерфейса нет

## 6. Критерии приёмки
- Приложение запускается командой `python main.py` без ошибок
- Рентабельность считается корректно, при нулевой выручке возвращается 0
- В репозитории есть README.md, requirements.txt, .gitignore и этот документ
